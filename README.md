## Register Your Mod

Want to publish your mod on Fusion?

1. Create a mod package following the Fusion mod format.
2. Include a `mod.json` manifest and mod icon.
3. Submit a registration request through this repository.
4. Once approved, your mod will be added to the catalog.

## About Fusion

Fusion is an independent Geometry Dash modding platform with its own mod loader, installer, and mod catalog.
